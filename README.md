# Hooman Ahmadi — Design & Product

Source files for Hooman Ahmadi’s portfolio at https://hoomanahmadi.com.

The portfolio is a static site: index.html, styles.css, chrome.css, five case studies under work/, and their visual assets. No build step is required.

## Résumé

The résumé PDF is intentionally excluded from this public repository. The production hosting supplies /assets/resume/Hooman-Ahmadi-Resume.pdf separately, allowing visitors to download it from the website. Do not add résumé PDFs to this repository.

## Hosting

The production website is hosted separately from this source mirror. Custom-domain routing and HTTPS are configured at the hosting provider and domain DNS provider.

## Local preview

Serve this directory with a static HTTP server. The résumé link requires the production-hosted file. The original design case studies remain accessible under their existing work/ paths.
